# 🛒 Проект "Предсказание покупок в интернет-магазине"

## Описание задачи

### Контекст проекта
Интернет-магазин собирает историю покупателей, проводит рассылки предложений и планирует будущие продажи. Для оптимизации процессов надо выделить пользователей, которые готовы совершить покупку в ближайшее время.

### Проблема
Необходимо предсказать вероятность покупки клиентом в течение 90 дней на основе исторических данных о покупках и маркетинговых рассылках.

### Цель проекта
Разработать модель машинного обучения для прогнозирования вероятности покупки клиентом в течение 90 дней.

### Основные задачи
- Исследование dataset (покупки, рассылки, целевые показатели)
- Предобработка данных: обработка дубликатов, преобразование типов, работа с аномалиями
- Разработка новых полезных признаков на основе истории покупок и взаимодействий
- Обучение модели для классификации пользователей
- Улучшение модели и максимизация метрики ROC-AUC
- Тестирование модели и интерпретация результатов

## Модель машинного обучения

### Алгоритм
XGBoost Classifier — градиентный бустинг на деревьях решений

### Гиперпараметры
```python
XGBClassifier(
    learning_rate=0.1,
    max_depth=3,
    n_estimators=200,
    subsample=0.8,
    scale_pos_weight=3.5
)
```

## Стратегия обработки дисбаланса целевого класса
-   scale_pos_weight --- компенсация дисбаланса

## Ключевые признаки ML-модели

### Признаки, которые сильнее всего влияют на целевой признак:
- most_frequent_plu_count - количество покупок самого частого товара у клиента
- channel_mobile_push - количество взаимодействий с клиентом через push-уведомления на мобильное устройство
- avg_purchase_sum - средняя стоимость одной покупки, средний чек
- most_frequent_plu - идентификатор товарной позиции (PLU), которую клиент покупал чаще всего
- purchase_period_days - количество дней между первой и последней покупкой клиента, длина клиентской истории
- most_frequent_plu_ratio - доля покупок самого частого товара от общего числа покупок клиента
- unique_campaigns - количество уникальных маркетинговых кампаний, в которые был включен клиент
- channel_email - количество взаимодействий с клиентом через электронную почту

### Признаки мало значимые для модели:
- unique_top20_plu - количество уникальных товаров из общего ТОП-20 популярных товаров, которые покупал клиент
- unique_plu_count - количество уникальных товарных позиций (PLU), которые покупал клиент 
- unique_purchase_days - количество уникальных дней, в которые клиент совершал покупки
