# 🛒 Проект "Предсказание покупок в интернет-магазине"

## Описание задачи

### Контекст проекта
Интернет-магазин собирает историю покупателей, проводит рассылки предложений и планирует будущие продажи. Для оптимизации процессов надо выделить пользователей, которые готовы совершить покупку в ближайшее время.

### Проблема
Необходимо предсказать вероятность покупки клиентом в течение 90 дней на основе исторических данных о покупках и маркетинговых рассылках.

### Цель проекта
Разработать модель машинного обучения для прогнозирования вероятности покупки клиентом в течение 90 дней.

### Основные задачи
- Исследование dataset (покупки, рассылки, целевые показатели)
- Предобработка данных: обработка дубликатов, преобразование типов, работа с аномалиями
- Разработка новых полезных признаков на основе истории покупок и взаимодействий
- Обучение модели для классификации пользователей
- Улучшение модели и максимизация метрики ROC-AUC
- Тестирование модели и интерпретация результатов

## Инструкция по запуску проекта

### Технические требования

- Pip (пакетный менеджер Python)
- Git

```bash
git clone https://github.com/Ckomopox80/Project_predicting_online_shopping.git
cd 
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```
